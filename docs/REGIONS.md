# 可選地區範例

下列分組依使用者確認的習慣設定，保留在插件設定頁「常用地區組合 → 可選地區範例」。它們不預填進清單、不作為預設地區，也不會自動出現在搜尋／對比的選單。選一項、按「加入清單」，可修改名稱及 ID，最後按「保存常用地區」才會加入快捷選單。其他國家／地區可自行搭配，不必使用任何範例；既有自訂清單不變。

快捷搜尋使用官方支援的逗號分隔 `place_id` 聯集，全球為 `place_id=any`；參見 [iNaturalist 搜尋網址說明](https://help.inaturalist.org/en/support/solutions/articles/151000170738)。
