# 使用說明

## 高階分類對比

觀察搜尋頁的「未观察的高阶」面板可指定使用者、地點、分類根與 rank。全部生物 ID：`48460`；鳥類 ID：`3`。地點接受多個逗號分隔的 ID，如 `6903,7613,7887,10301`；`any` 表示全球。

計算的是「區域記錄中存在的指定 rank 分支」減去「使用者全球觀察中曾出現的該 rank 分支」。看到某目的任一下層類群就算看過該目；只鑑定到鳥綱不會推定看過其全部目。表格的觀察數包含當地整個後代分支的記錄。Leaf taxa 可另外向官方 `species_counts` 核驗。

使用官方 taxonomy API 共用快取；只換 rank 不需要重新下載兩棵分類樹，多地點以聯集處理，避免把交疊地區的數字直接相加。

## 上傳 AI 助手

在 `/observations/upload` 加入照片後，按「僅檢查建議」可預覽，或按「一鍵套用 AI 首選」逐一處理卡片。預設保留既有 taxon 與手動文字。

- 第一個最佳建議的視覺分數嚴格大於門檻才套用，预設門檻 80；80 分本身不符合。
- 分數缺失時，只有官方「非常確定它屬於這個……」提示出現才套用。選的是提示下方的第一個最佳建議，不是共同祖先。
- 已有可讀分數但未達門檻，不會改用提示放行；另有「只看官方提示」模式供選擇。
- 視覺分數不是經校準的實際正確率；對某屬很確定不表示下方物種也同樣確定。
- 不改選分數更高的第二項；沿用網站的排序、附近條件與辨識縮圖。

取消「保留已填寫的分類／文字」後，手動批次可替換已有分類，但只在候選符合規則時替換。自動模式始終只處理空白照片卡片。

「自動處理空白觀察」處理本頁目前及之後新增的卡片，每張在一次開啟期間只嘗試一次。模式不跨頁儲存，失敗或低分不反覆請求。更換照片、補完資料或網路恢復後，可手動再次執行。

「停止」保留已填結果，取消後續選取。正在處理時，面板外的點擊、打字、拖曳或編輯會停止批次；空閒等待新照片時可繼續操作網站。遲到的辨識回應不會在停止後被套用。「僅檢查」不填分類，並關閉自動模式。

正常情況依序查詢，間隔 1.2 秒，沿用網站快取；等待 30 秒逾時會略過。已上傳、正在上傳、沒有照片或查詢期间内容被改動的卡片會略過。插件只填寫草稿，最終由使用者檢查並按網站上傳按鈕。
