Privacy policy

Last updated: 30 September 2026

Browser extension

Leafwise uses iNaturalist page content, public usernames and observation IDs, search filters, and AI suggestion scores to provide its features. Preferences and saved searches are stored in browser storage; some settings may sync through your browser. Public API results are cached briefly.

Selected public usernames, taxon IDs, place IDs, and filters are sent to the public iNaturalist API. iNaturalist itself handles photo identification; Leafwise reads the same request's scores and does not send photos to a separate AI service. The extension does not access passwords, authentication tokens, private coordinates, private messages, or unrelated websites.

There are no ads, analytics, or telemetry in the extension. The developer does not receive your photos, scores, or notification contents, and does not sell user data. Upload assistance modifies drafts only; it never automatically submits observations.

Leafwise Store Automation (maintainer only)

When configured, the companion OAuth application uses the Chrome Web Store permission to read the maintainer's listing metadata and publishing status, upload extension packages, and submit updates for review. It is not a Google sign-in feature for extension users and does not request access to Gmail, contacts, or Google Drive.

The maintainer's OAuth client secret and refresh token are stored in GitHub Actions secrets and used only by the publishing workflow to obtain access tokens for Google. Credentials are never bundled with the extension or published on this site. Google and GitHub process the requests needed to operate this workflow; publishing logs may contain listing IDs, versions, and operation statuses, not credentials. This information is not sold, used for advertising, or used to train AI models.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. The maintainer can stop automation, delete the GitHub secrets, and revoke Google's authorization. Credentials are retained in those secrets until removed or replaced.

Website, controls, and contact

This static site has no forms, JavaScript, analytics, or tracking code. GitHub Pages hosts it and may process standard request logs under GitHub's privacy statement.

Extension users can remove saved items in Leafwise and clear extension data using their browser's storage and sync controls. For questions, contact the maintainer through GitHub issues; do not post credentials or private data. The extension's detailed privacy policy is also available.
