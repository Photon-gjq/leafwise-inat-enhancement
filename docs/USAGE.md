# 使用說明

## 高階分類對比

觀察搜尋頁的「類群對比」面板可指定使用者、地點、分類根與 rank。全部生物 ID：`48460`；鳥類 ID：`3`。地點接受多個逗號分隔的 ID；「中國大陸+港澳臺」為 `6903,7613,7887,10301`，`any` 表示全球。

四種模式都先取得當地候選分支：

- **生涯未見**：排除個人全球所有記錄中曾出現的分支。
- **已見，但該年未見**：只保留個人生涯見過的分支，再排除指定年份的全球記錄。
- **已見，但此地未見**：只保留個人生涯見過的分支，再排除指定地點聯集內的個人記錄。
- **該年首次記錄**：該年個人全球有記錄，而且該年以前没有有日期的記錄；只列出當地候選清單中也存在的分支。

看到某目的任一下層類群就算看過該目；只鑑定到鳥綱不會推定看過其全部目。年份按觀察日期計算，並非上傳日期；無日期記錄不參與年份對比。補錄更早的觀察、刪除紀錄或分類變更都可能改變首次記錄結果。表格的觀察數包含當地整個後代分支。Leaf taxa 可另外向官方 `species_counts` 核驗。

使用官方 taxonomy API 共用快取；只換 rank 不需要重新下載兩棵分類樹，多地點以聯集處理，避免把交疊地區的數字直接相加。

## 季節清單與當地篩選

「這個月份可以找什麼」填入目前月份、清除當地開始／結束日期、切回生涯未見並按觀察數排序；檢查地點和類群後按開始對比。月份如 `3,4,5` 代表歷年這幾個月；日期和項目 ID 可進一步縮小候選清單。這些條件及當地品質不會限制個人基準，所以某月沒有記錄不會被誤當成生涯未見。

「讀取目前頁面」帶入月份、日期及數字項目 ID；對比以上方面板顯示的條件為準。地圖框、排除條件等不參與對比，收藏仍會完整保存原搜尋網址。月份觀察數反映平台記錄，不能直接當成遇見機率。

## 收藏與分區

在地點下拉選單選擇內建或自訂分區，下方顯示成員及 ID。[分區清單](REGIONS.md)採使用者確認的分組；華南含港澳，華東不含臺灣。修改 ID 後，展開「查詢收藏與自訂地點組合」、輸入名稱並保存。選中自訂項目可更新或刪除；修改內建項目會另存一份。

查詢收藏同時保存整個觀察搜尋網址及目前有效的對比設定。選「新增查詢收藏」建立一筆；選現有收藏可改名／更新、載入或刪除。載入時會恢復搜尋網址及面板，但不自動發起對比。每類最多 50 筆，地點組合最多 20 個不同 ID。收藏保存在此瀏覽器，完整網址可能包含個人查詢條件。

## 複製和匯出

「複製結果」「匯出 CSV」包含所有符合目前名稱篩選的結果，依目前排序，不限於當頁 50 筆。已核驗的 Leaf taxa 使用官方值；中文名尚未載入時仍保留學名。CSV 採 UTF-8 BOM 並防止名稱被試算表當成公式；附地點、月份、日期、年份、使用者與其他對比參數。匯出只使用現有結果，不增加查詢。瀏覽器拒絕剪貼簿寫入時會提供可選取的文字框，按 Ctrl/Cmd+C 複製即可。

## 我的紀錄小卡

在觀察詳情或類群頁，點擊名稱旁的個人觀察次數，可查看首次與最近的觀察日期、公开位置文字及連結，另保留「查看全部」入口。Ctrl/Cmd 點擊次數仍可直接另開完整清單。首次／最近依有日期的公開觀察排序，包含該類群及後代；不是上傳先後。

僅點開時查詢，兩次 `per_page=1` 請求、快取 5 分鐘。錯誤會顯示重試，不把連線失敗當成沒有記錄。小卡不修改觀察，也不讀取隱藏位置。

## 上傳 AI 助手

在 `/observations/upload` 中，AI 助手預設收合在原生「全選」右側；快捷按鈕可直接執行而不展開。展開後完整面板回到右側照片欄，左側批次日期、時間及地點欄保持原位。展開狀態保存在本機。加入照片後，按「僅檢查建議」可預覽，或按「一鍵套用 AI 首選」逐一處理卡片。預設保留既有 taxon 與手動文字。

- 第一個最佳建議的綜合分數嚴格大於門檻時套用該首選，預設門檻 80；80 分本身不符合。
- 首選分數未超過門檻或無法讀取時，若有官方「非常確定它屬於這個……」提示，就直接填入該區塊中的上階類群；不會選取下方較細的最佳建議。
- 首選未達門檻且沒有可選的官方確定類群時保留原值。另有「只填官方非常確定類群」模式，完全忽略首選分數。以回報中的情況為例，官方只確定到葉甲科時會填葉甲科，不會填入 5.39 分的黃帶芫菁屬。
- 候選顯示為「綜合分數（視覺分數）」，例如 `86.0(75.2)`。前者取自 `combined_score`，結合網站請求中可用的視覺、地點與日期；括號內取自 `vision_score`，只反映模型的視覺相似度。兩者都不是經校準的實際正確率，也不適合跨不同觀察比較；介面因此不加百分號。批次門檻與自動選擇始終只使用前面的綜合分數。
- 不改選分數更高的第二項；沿用網站的排序、附近條件與辨識縮圖。

任何 `/observations/<數字 ID>` 觀察詳情頁開啟原生鑑定建議時，都使用相同的「綜合分數（視覺分數）」格式。數字沒有背景框、邊框、百分號或候選列色條；只有分類 ID 與網站原生視覺候選吻合、且綜合分數有效時才顯示，手動文字搜尋結果不補分，沒有綜合分數時也不會把純視覺分數冒充綜合分數。

取消「保留已填寫的分類／文字」後，手動批次可替換已有分類，但只在候選符合規則時替換。自動模式始終只處理空白照片卡片。

「自動處理空白觀察」處理本頁目前及之後新增的卡片，每張在一次開啟期間只嘗試一次。模式不跨頁儲存，失敗或低分不反覆請求。更換照片、補完資料或網路恢復後，可手動再次執行。

「停止」保留已填結果，取消後續選取。正在處理時，面板外的點擊、打字、拖曳或編輯會停止批次；空閒等待新照片時可繼續操作網站。遲到的辨識回應不會在停止後被套用。「僅檢查」不填分類，並關閉自動模式。

正常情況依序查詢，間隔 1.2 秒，沿用網站快取；等待 30 秒逾時會略過。已上傳、正在上傳、沒有照片或查詢期间内容被改動的卡片會略過。插件只填寫草稿，最終由使用者檢查並按網站上傳按鈕。
