# 使用說明

## 新動態通知

下拉清單內的「僅顯示非完全贊同的鑑定」開關預設關閉，開關狀態保存在此瀏覽器。啟用後按需讀取公開鑑定記錄，只隱藏與你在消息產生之前的有效鑑定完全相同、且沒有文字說明的鑑定。其他類群、更細或更粗的分類均保留；評論、附帶說明及資料缺失／撤回／後來修改等無法可靠判斷的消息也保留，不使用目前社群分類作基準。

篩選期間開啟按鈕暫時禁用；完成後「開啟篩選後的觀察（數量）」只開可見通知對應的觀察，同一觀察有多條保留的通知仍只開一次。關閉開關可恢復原清單。此篩選只處理網站已載入的下拉清單，不另行查詢全部未讀或歷史通知；網站沒有未讀時可能回顯已讀消息。

在 iNaturalist 網站右上角點開對話氣泡形的「新動態」清單後，按「一鍵開啟這些觀察（數量）」可把目前清單中有觀察連結的通知開成背景分頁。同一觀察的可解析通知只開一個分頁；私訊、儀表板及已確認非觀察的目的地不會開啟。數量按目前已載入的清單計算，並非所有歷史通知。操作不會替你點開每則通知，也不會額外將通知標記為已讀；iNaturalist 本身可能在展開清單時更新未讀數。

觀察上的提及（@）、收藏、評論及鑑定都納入開啟；提及消息不會被完全贊同篩選隱藏。提及連結需先解析到觀察，按鈕短暫禁用；若解析失敗或要求登入，仍開啟原通知連結，不靜默漏掉，此時只能按原連結去重，可能無法合併同一觀察的不同連結。已知指向日誌等非觀察的通知略過。

## 高階分類對比

深灰統計列的地區區塊包含「類群對比」、常用類群及地點組合快捷選單，不再增加白色標頭高度。「用戶篩選」已收進類群對比面板：展開面板、點用戶摘要，即可選擇觀察來源和排除已觀察的用戶、互換並套用。套用仍只更新搜尋用戶條件，不會執行類群對比；原生過濾器內的來源／排除控制項也保留。關閉面板會隱藏用戶表單，重新展開保留同頁草稿。

「常用類群」直接選擇後更新 `taxon_id` 及可選 `without_taxon_id`，保留地點、用戶、用戶排除、日期和其他條件，回到第一頁；「不限」清除這兩個類群條件。不自動開始對比。選「管理常用類群…」開啟設定，每行填 `ID = 名稱`，可增刪、排序或留空保存以清空；名稱可省略，既有格式保持相容。

例如 `125816 !50186 = 我的組合` 會套用 `taxon_id=125816&without_taxon_id=50186`；`!` 後可填逗號分隔的排除 ID，每項最多 20 個。同一根類群可保存不同排除組合；選普通條目會清除上一組的類群排除，不會殘留。快捷選單與類群對比共用設定，但帶排除條件的條目只用於搜尋快捷選擇，不出現在尚不支援排除統計的對比選單。保存設定只更新選項、不改當前搜尋，既有自訂名稱也不會被翻譯。

鑑定頁 `/observations/identify` 的類群及地區快捷選單分別對齊原生物種與地區輸入框，寬度跟隨原生欄位。選取時保留「已檢視」、品質、用戶及其他條件，只重新載入搜尋，不會提交鑑定或標記已檢視。地區「全球」明確使用 `place_id=any`，不會因帳號預設地區再次限縮；原生禁用及 blind 實驗模式不啟用快捷選單。

觀察搜尋頁的「類群對比」面板可指定使用者、地點、分類根與 rank；統計層級支援界、門、綱、目、亞目、總科、科、亞科、族、屬、亞屬及種。全部生物 ID：`48460`；鳥類 ID：`3`。地點接受多個逗號分隔的 ID；「中國大陸+港澳」為 `6903,7613,10301`，「中國大陸+港澳臺」為 `6903,7613,7887,10301`，`any` 表示全球。

四種模式都先取得當地候選分支：

- **生涯未見**：排除個人全球所有記錄中曾出現的分支。
- **已見，但該年未見**：只保留個人生涯見過的分支，再排除指定年份的全球記錄。
- **已見，但此地未見**：只保留個人生涯見過的分支，再排除指定地點聯集內的個人記錄。
- **該年首次記錄**：該年個人全球有記錄，而且該年以前没有有日期的記錄；只列出當地候選清單中也存在的分支。

看到某目的任一下層類群就算看過該目；只鑑定到鳥綱不會推定看過其全部目。選擇種級時，亞種等種下分類會歸入其所屬物種；只鑑定到屬等較高層級不會推定看過其所有物種。年份按觀察日期計算，並非上傳日期；無日期記錄不參與年份對比。補錄更早的觀察、刪除紀錄或分類變更都可能改變首次記錄結果。表格的觀察數包含當地整個後代分支。Leaf taxa 可另外向官方 `species_counts` 核驗。

使用官方 taxonomy API 共用快取；只換 rank 不需要重新下載兩棵分類樹，多地點以聯集處理，避免把交疊地區的數字直接相加。

## 季節清單與當地篩選

「這個月份可以找什麼」填入目前月份、清除當地開始／結束日期、切回生涯未見並按觀察數排序；檢查地點和類群後按開始對比。月份如 `3,4,5` 代表歷年這幾個月；日期和項目 ID 可進一步縮小候選清單。這些條件及當地品質不會限制個人基準，所以某月沒有記錄不會被誤當成生涯未見。

「讀取目前頁面」帶入月份、日期及數字項目 ID；對比以上方面板顯示的條件為準。地圖框、排除條件等不參與對比，收藏仍會完整保存原搜尋網址。月份觀察數反映平台記錄，不能直接當成遇見機率。

## 收藏與分區

觀察搜尋欄下方的「快速選擇地點組合…」可直接選擇已保存的組合，不必打開類群對比。選取後立即更新搜尋：保留使用者、類群、日期、品質、項目與排除條件；取代地點 ID、清除旧地圖框／圓形半徑並回到第一頁。「全球」使用 `place_id=any`。不自動開啟類群對比或發起對比請求。

選單的「管理常用地區…」開啟插件設定頁。每行 `ID,ID = 名稱`，保存後兩處選單同步更新，但不套用到當前搜尋。原有中國及分區組合放在設定頁「可選地區範例」，按「加入清單」後仍須保存；不預填、不預設、不覆蓋既有自訂名稱。[範例成員](REGIONS.md)可核對 ID。其他地區可直接自訂。

類群對比的地點下拉選單只列全球與已保存的組合，下方顯示成員及 ID。也可輸入 ID，展開「查詢收藏與自訂地點組合」、輸入名稱並保存。選中自訂項目可更新或刪除。沒有地點條件時，空白欄以 `any`（全球）對比，不會退回中國範圍。

查詢收藏同時保存整個觀察搜尋網址及目前有效的對比設定。選「新增查詢收藏」建立一筆；選現有收藏可改名／更新、載入或刪除。載入時會恢復搜尋網址及面板，但不自動發起對比。每類最多 50 筆，地點組合最多 20 個不同 ID。收藏保存在此瀏覽器，完整網址可能包含個人查詢條件。

## 複製和匯出

「複製結果」「匯出 CSV」包含所有符合目前名稱篩選的結果，依目前排序，不限於當頁 50 筆。已核驗的 Leaf taxa 使用官方值；中文名尚未載入時仍保留學名。CSV 採 UTF-8 BOM 並防止名稱被試算表當成公式；附地點、月份、日期、年份、使用者與其他對比參數。匯出只使用現有結果，不增加查詢。瀏覽器拒絕剪貼簿寫入時會提供可選取的文字框，按 Ctrl/Cmd+C 複製即可。

## 我的紀錄小卡

分類頁的個人統計顯示 `(觀察數|最低分類單元數|種級數)`，例如 `(8541|2747|2122)`。第一項是這個類群及其後代的個人觀察數；第二項沿用搜尋頁「種物種」的統計口徑，計入有觀察的最低分類單元，即使該單元是科或屬；第三項沿用觀察者表格「物種」欄，只計種級分類單元。三項都使用該使用者、該分類單元及 `verifiable=any`；API 失敗時保留已取得的觀察數，不把未知數顯示成 0。分類樹中其他有紀錄的單元也按相同格式顯示；沒有個人紀錄仍顯示 🆕。

在觀察詳情或類群頁，點擊名稱旁的個人觀察次數，可查看首次與最近的觀察日期、公开位置文字及連結，另保留「查看全部」入口。Ctrl/Cmd 點擊次數仍可直接另開完整清單。首次／最近依有日期的公開觀察排序，包含該類群及後代；不是上傳先後。

僅點開時查詢，兩次 `per_page=1` 請求、快取 5 分鐘。錯誤會顯示重試，不把連線失敗當成沒有記錄。小卡不修改觀察，也不讀取隱藏位置。

## 上傳 AI 助手

在 `/observations/upload` 中，AI 助手預設收合在原生「全選」右側；快捷按鈕可直接執行而不展開。展開後完整面板回到右側照片欄，左側批次日期、時間及地點欄保持原位。展開狀態保存在本機。加入照片後，按「僅檢查建議」可預覽，或按「一鍵套用 AI 首選」逐一處理卡片。預設保留既有 taxon 與手動文字。

- 第一個最佳建議的綜合分數嚴格大於門檻時套用該首選，預設門檻 80；80 分本身不符合。
- 首選分數未超過門檻或無法讀取時，若有官方「非常確定它屬於這個……」提示，就直接填入該區塊中的上階類群；不會選取下方較細的最佳建議。
- 首選未達門檻且沒有可選的官方確定類群時保留原值。另有「只填官方非常確定類群」模式，完全忽略首選分數。以回報中的情況為例，官方只確定到葉甲科時會填葉甲科，不會填入 5.39 分的黃帶芫菁屬。
- 候選顯示為「綜合分數（視覺分數）」，例如 `86.0(75.2)`。前者取自 `combined_score`，結合網站請求中可用的視覺、地點與日期；括號內取自 `vision_score`，只反映模型的視覺相似度。兩者都不是經校準的實際正確率，也不適合跨不同觀察比較；介面因此不加百分號。批次門檻與自動選擇始終只使用前面的綜合分數。
- 不改選分數更高的第二項；沿用網站的排序、附近條件與辨識縮圖。

兩個數字均保留 API 的原始 0–100 數值，不按大小推測單位或乘以 100。正值小於 1 時顯示三位有效數字，例如 `0.316(0.382)`；其他值維持一位小數。滑鼠提示可查看未四捨五入原值，文字格式不影響配對及門檻判定。

任何 `/observations/<數字 ID>` 觀察詳情頁開啟原生鑑定建議時，都使用相同的「綜合分數（視覺分數）」格式。數字沒有背景框、邊框、百分號或候選列色條；只有分類 ID 與網站原生視覺候選吻合、且綜合分數有效時才顯示，手動文字搜尋結果不補分，沒有綜合分數時也不會把純視覺分數冒充綜合分數。

取消「保留已填寫的分類／文字」後，手動批次可替換已有分類，但只在候選符合規則時替換。自動模式始終只處理空白照片卡片。

「自動處理空白觀察」處理本頁目前及之後新增的卡片，每張在一次開啟期間只嘗試一次。模式不跨頁儲存，失敗或低分不反覆請求。更換照片、補完資料或網路恢復後，可手動再次執行。

「停止」保留已填結果，取消後續選取。正在處理時，面板外的點擊、打字、拖曳或編輯會停止批次；空閒等待新照片時可繼續操作網站。遲到的辨識回應不會在停止後被套用。「僅檢查」不填分類，並關閉自動模式。

正常情況依序查詢，間隔 1.2 秒，沿用網站快取；等待 30 秒逾時會略過。已上傳、正在上傳、沒有照片或查詢期间内容被改動的卡片會略過。插件只填寫草稿，最終由使用者檢查並按網站上傳按鈕。
