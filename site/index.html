Leafwise

Practical tools for exploring and recording nature on iNaturalist.

iNaturalist browser extension

Leafwise adds taxon comparisons, personal observation statistics, saved searches and place groups, AI suggestion scores, upload-draft assistance, and duplicate-free notification tabs. The interface is in Chinese; an English guide is available.

AI scores come from iNaturalist and are not calibrated accuracy estimates. Leafwise edits drafts only: you review and submit observations yourself. This is an independent project, not an official iNaturalist product.

Leafwise Store Automation

This companion OAuth application is for the project maintainer's GitHub Actions workflow. With the maintainer's authorization, it uploads extension packages to the maintainer's existing Chrome Web Store listing and submits updates for review.

Extension users do not sign in to this application or grant it access to their Google accounts. Publishing credentials are not included in the extension. Edge and Firefox use their separate store publishing credentials.
