# Leafwise privacy policy

Leafwise enhances iNaturalist pages in Chrome, Edge, and Firefox. It reads the iNaturalist page and the public iNaturalist API only to provide the user-facing features described in the [English guide](GUIDE.en.md): saved searches and place groups, observation and taxon comparisons, AI suggestion scores, batch editing of upload drafts, and opening observation notifications. It does not automatically submit observations.

The extension handles public iNaturalist usernames and observation IDs, observation-page content, user-selected search URLs and location filters, and AI suggestion taxon IDs and scores. Usernames, saved searches, place groups, and preferences are stored in browser storage; some may sync through the browser's own sync service when enabled. Public API results are cached briefly in browser memory or session storage. AI scores and notification contents are used in the current page and are not sent to the developer. The notification action opens one background tab per distinct observation only when clicked.

For comparison and personal-count features, Leafwise sends the selected public username or ID, taxon ID, place ID, and query filters to `https://api.inaturalist.org/` over HTTPS. It does not send them to a Leafwise server. For AI suggestions, iNaturalist itself sends the image and available date/location to its own identification service; Leafwise reads the existing response and, where necessary, requests the two score fields in that same request. Leafwise does not create a separate image-identification request. It does not access passwords, authentication tokens, private coordinates, messages, or data from unrelated websites.

Leafwise has no advertising, analytics, telemetry, external proxy, or third-party AI service. It does not sell or transfer user data outside the functions above, use data for unrelated purposes, or use data for creditworthiness or lending. No developer-operated server receives users' data. The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Users can remove saved searches and place groups in the extension interface and can remove other local or synced extension data using their browser's extension and sync controls. The [source code and support issues](https://github.com/Photon-gjq/leafwise-inat-enhancement) are public. This policy is updated when Leafwise's data practices change.
