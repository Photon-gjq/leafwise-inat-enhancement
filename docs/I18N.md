# 跟隨 iNaturalist 的界面語言

1.1.0 起，更改 iNaturalist 的語言設定並重新載入頁面，Leafwise 的自有控制項即跟隨網站語言，不以瀏覽器語言覆蓋網站設定。設定頁使用最近一次網站語言；尚未訪問網站時才使用瀏覽器語言。未知語言以英文後備。

這是維護者選取、使用者確認的 **50 個常用語言／地區版本**，不是 iNaturalist 官方使用率前 50 名，也不是 50 個彼此不同的語言。來源清單為 `src/i18n/locales.json`；iNaturalist 官方支援清單見 [i18n 初始化檔](https://github.com/inaturalist/inaturalist/blob/main/config/initializers/i18n.rb)。網站語言讀取依據是其 [HTML 模板](https://github.com/inaturalist/inaturalist/blob/main/app/views/layouts/bootstrap.html.erb) 的 `lang`／`Content-Language`。

## 首版範圍與限制

- 英文、簡中、繁中、香港繁中覆蓋目前登記的所有文案。中文地區文案在建置時由 OpenCC 轉換，非逐句人工地區潤色。
- 其餘基礎語言有主要按鈕、欄位、分類層級、對比模式、分數說明、通知按鈕、常用狀態和匯出欄名的翻譯。長篇統計說明及部分少見錯誤先用英文後備；不宣稱全量翻譯完成。
- 英文地區版本、法語加拿大、西班牙語地區及葡語巴西目前沿用基礎語言，不宣稱完成地區措辭差異校對。這批翻譯尚未經所有語言的母語者審校。
- 不翻譯原生網站、使用者名稱、自訂收藏／分組／分類名稱或 API 返回的資料。分類通俗名透過同一公開名稱查詢請求的 `locale` 取得；找不到名稱仍使用學名。不改分類 ID 或查詢的統計範圍。
- 網站正常更改語言會重新載入頁面；不保證透過開發者工具直接更改 `html.lang` 後，所有已建立的表單立即重繪。重新開啟設定頁即可同步已記住的語言。
- 這次只本地化 Leafwise 的界面；不擴充對 iNaturalist 私有元件的語言判讀規則。原生 AI 元件、登入、草稿流程需在實際使用的網站語言下另做驗收。

## 50 個語言／地區版本

English (`en`, `en-US`, `en-GB`, `en-CA`)、简体中文 (`zh-CN`)、繁體中文 (`zh-TW`)、香港繁體 (`zh-HK`)、Español (`es`, `es-AR`, `es-CO`, `es-CR`, `es-MX`)、Français (`fr`, `fr-CA`)、Português (`pt`, `pt-BR`)、Deutsch (`de`)、Русский (`ru`)、日本語 (`ja`)、한국어 (`ko`)、Italiano (`it`)、Nederlands (`nl`)、Polski (`pl`)、Українська (`uk`)、Čeština (`cs`)、Svenska (`sv`)、Dansk (`da`)、Norsk bokmål (`nb`)、Suomi (`fi`)、Türkçe (`tr`)、العربية (`ar`)、עברית (`he`)、Bahasa Indonesia (`id`)、Bahasa Melayu (`ms`)、Tiếng Việt (`vi`)、ไทย (`th`)、हिन्दी (`hi`)、فارسی (`fa`)、Română (`ro`)、Magyar (`hu`)、Ελληνικά (`el`)、Slovenčina (`sk`)、Български (`bg`)、Hrvatski (`hr`)、Српски (`sr`)、Slovenščina (`sl`)、Català (`ca`)、Eesti (`et`)、Lietuvių (`lt`)、Latviešu (`lv`)。

`zh-Hans`／`zh-Hant`／`zh-Hant-HK` 和底線拼法會正規化；`iw` 對應希伯來語 `he`。阿拉伯語、希伯來語及波斯語只在插件自有模板／設定頁設定 `dir=rtl`，不改網站其他元素。

## 後续維護

- `src/i18n/source.json`：舊中文文案到穩定英文 key 的對照，方便保持核心／服務的既有錯誤契約。新增界面文案時先登記；動態值用 `{0}`、`{1}` 等佔位符。
- `src/i18n/<language>.json`：英文 key 到翻譯。缺失 key 明確以英文後備；不要把英文複製進其他語言目錄來假裝覆蓋率提高。區域版本可新增同名 JSON 覆寫。
- `src/i18n/place-settings.json`：新增地區設定主要控制項的小型補充目錄；在建置時合併到同一語言資料，不增加執行時網路請求。
- `src/i18n/quick-places.json`：外層快捷地區選單、管理及可選範例主要控制項的翻譯補充；遵守同一 50 個語言／地區版本及英文後備規則，自訂名稱不翻譯。
- `src/i18n/notification-filter.json`：通知篩選開關、說明、載入／不確定提示及篩選後開啟按鈕；37 個基礎語言隨既有地區繼承規則覆蓋全部 50 個版本，中文仍由 source 產生。這五個 key 均列為必需；尚需母語者校對。
- `src/i18n/required-keys.json`：50 個版本必須覆蓋的主要控制項；缺少、空字串或佔位符不符會令建置失敗。不是全部文案清單。
- `scripts/i18n.mjs`：建置資料目錄、中文轉換、明列的控制項別名及驗證；產生一份隨包附帶的 `scripts/i18n-catalog.js`。不要手改生成物。
- `src/scripts/i18n.js`：只處理呈現。`t()` 插入值不會再次當成翻譯或 HTML；`html()` 只在插件固定模板建立時用 DOM 文字／屬性方法翻譯；`legacy()` 只識別已登記的固定錯誤／決策文案。不得全頁掃描替换，不得翻譯 CSS、資料、選項 value 或 API payload。
- 新增本機鍵 `storage.local.leafwiseLastSiteLocale` 只保存語言碼；舊同步設定鍵保持不變。名称快取使用包含 locale 的完整 API URL，不把不同語言混用。
- 翻譯全部隨擴充附帶，運行時不呼叫翻譯服務、不新增權限或遠端腳本。OpenCC 只在建置時使用。
- 執行 `npm run check`、`npm run test:layout`、`npm run package`。功能測試驗證 50 個目錄和佔位符；瀏覽器測試覆蓋全部 50 個通知按鈕及代表語言的上傳版面、資料保留、英文後備與 RTL。這不等於 50 種語言的正式帳號／母語人工驗收。

## English summary

Leafwise follows iNaturalist's site language after reloading. Settings reuse the most recent site language. The initial 50 **locale variants** are a curated selection, not an official usage ranking. Main UI strings are translated; detailed help and some uncommon errors fall back to English. Regional variants currently inherit their base language, except for the three generated Chinese variants. Native-speaker review is still needed. User data and native website content are never translated. All catalogs are bundled locally, with no translation network service or extra permission.
